# SIT720 8.1D – Housing Price Prediction

This repository contains the complete project files for the SIT720 8.1D Housing Price Prediction task.

## Project Contents

- `SIT720_8.1D_Housing.ipynb` – Jupyter Notebook containing the data analysis, preprocessing, machine learning models, evaluation, and project experiments.
- `sydney_housing_realestate_105.csv` – Collected Sydney housing dataset used for the project.
- `app.py` – Source code for the Streamlit housing price prediction application.
- `best_model.pkl` – Trained machine learning model used by the application.
- `part5_comparison.csv` – Results from the comparison conducted in Part 5.
- `part5_mae_results.csv` – Mean Absolute Error results.
- `part5_mape_results.csv` – Mean Absolute Percentage Error results.
- `requirements.txt` – Python packages required to run the project.

## Machine Learning

The project includes data preprocessing, exploratory data analysis, model training and evaluation for housing price prediction.

The trained model is saved as `best_model.pkl` and is used by the Streamlit application.

## Dataset

The project uses a collected Sydney housing dataset containing 105 property records. The dataset is included in this repository for reproducibility and assessment purposes.

## Application

The project includes a Streamlit application (`app.py`) that uses the trained machine learning model to generate housing price predictions.

## Reproducibility

The Jupyter Notebook, dataset, trained model, application source code, output files and required Python packages are provided in this repository to support reproduction and evaluation of the project.
